# SweMaMi
HT25 30 credit project. 

This study focuses on comparing the feacal microbiome at different time points in women with consecutive pregnancies in the same participant. This has not been done before as previous studies have mainly studied the effect parity has on microbiome by comparing samples taken from different individuals. Here samples were collected from the same women during consecutive pregnancies allowing for the study of the microbiome across parity.
